# 💱 Currency Converter

A simple and responsive **Currency Converter web app** built using **HTML, CSS, and JavaScript**.  
It allows users to convert one currency into another using real-time exchange rates with a clean and user-friendly interface.

## 🚀 Features
- Convert one currency to another
- Real-time exchange rate integration
- Clean and responsive UI
- Easy-to-use input and dropdown selection

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Exchange Rate API
